# Guía de Fundamentos de Software Mantenible
Guía didáctica que reúne conceptos básicos para escribir software más legible, mantenible y fácil de evolucionar, realizada con material de apoyo.
Elaborada a partir de apuntes propios, práctica docente y material de apoyo especializado sobre buenas prácticas de diseño de software.

## Contenidos
- 01 Clean Code
- 02 Programación Orientada a Objetos
- 03 Reglas del diseño simple
- 04 Principios SOLID
